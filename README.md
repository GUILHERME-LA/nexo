# Nexo 📰

**Portal editorial de inteligência política** — monitoramento, clipping e análise de sentimento em tempo real do cenário político brasileiro.

[![Vercel](https://img.shields.io/badge/🔗_Acessar_App-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://nexo-azure-beta.vercel.app)

---

## ✨ Funcionalidades

- 📡 **Monitoramento em tempo real** de notícias políticas
- ✂️ **Clipping automático** com categorização por tema
- 📊 **Análise de sentimento** usando NLP
- 🏷️ **Tags e categorização** inteligente de conteúdo
- 🔍 **Busca avançada** com filtros
- 📱 **Layout responsivo** e otimizado

## 🚀 Como Executar Localmente

```bash
# Clone o repositório
git clone https://github.com/GUILHERME-LA/nexo.git

# Acesse a pasta
cd nexo

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```
